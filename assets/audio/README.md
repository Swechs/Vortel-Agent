# Audio Assets

Bu klasöre ses örneklerini `.mp3` formatında ekleyin:

- `beauty-salon.mp3` — Güzellik salonu randevu asistanı demo ses kaydı
- `dental-clinic.mp3` — Diş kliniği bilgi ve randevu asistanı demo ses kaydı
- `auto-detailing.mp3` — Oto detailing / PPF teklif asistanı demo ses kaydı

Ses dosyaları eklendikten sonra `constants/Data.ts` içindeki `AUDIO_SAMPLES` dizisine dosya yollarını ekleyin.
